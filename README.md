# RevenueRescue AI

AI-powered Revenue Recovery Agent — detects failed payments, abandoned
checkouts, and unpaid invoices, scores each one's recovery probability,
and automates personalized recovery actions.

See `/docs` (architecture, database schema, API specification, folder
structure) if included alongside this package, or refer to your project
notes for the full design documents.

## Stack

- **Backend:** FastAPI + MongoDB (Motor) + Celery/Redis + Claude API (Anthropic) + Razorpay
- **Frontend:** React + TypeScript + Vite + Tailwind CSS + Recharts

## Prerequisites

- Python 3.11+
- Node.js 18+
- MongoDB (local or Atlas)
- Redis (local or managed)
- An Anthropic API key
- A Razorpay account (test-mode keys are fine for local dev)

## Backend setup

```bash
cd backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# Edit .env: set MONGO_URI, REDIS_URL, JWT_SECRET_KEY, ANTHROPIC_API_KEY,
# and Razorpay keys at minimum.

# Terminal 1 — API server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# Terminal 2 — Celery worker (required for webhook processing, scoring,
# and notifications to actually run)
celery -A app.workers.celery_app worker --loglevel=info
```

API docs (auto-generated by FastAPI) will be at `http://localhost:8000/docs`.

## Frontend setup

```bash
cd frontend
npm install

cp .env.example .env
# Edit .env: set VITE_API_BASE_URL if your backend isn't on localhost:8000

npm run dev
```

App will be at `http://localhost:5173`.

## First run

1. Register a business + admin user:
   ```bash
   curl -X POST http://localhost:8000/api/v1/auth/register \
     -H "Content-Type: application/json" \
     -d '{
       "business_name": "Test Business",
       "admin_name": "Your Name",
       "email": "you@example.com",
       "password": "StrongPass!2026"
     }'
   ```
2. Sign in at `http://localhost:5173/login` with that email/password.
3. Configure your Razorpay webhook URL (per business) as:
   `https://<your-host>/api/v1/webhooks/razorpay/{business_id}`

## Known v1 limitations

- `notification_service.py` logs email/SMS/WhatsApp sends in dev mode
  until real provider SDK calls are wired into its `TODO` stubs.
- `model_infer.py` is a hand-tuned heuristic, not a trained ML model —
  swap in a trained artifact once historical outcome data exists.
- No frontend Register page yet — use the curl command above, or add
  one following the pattern in `src/pages/Login.tsx`.
- No `/auth/refresh` endpoint wired up yet — re-login after the access
  token expires (1 hour by default).
